# chat-role-play frontend

## Getting Started

run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## library

- 状態管理: jotai
- 認証認可: auth0
- CSS: https://tailwindcss.com/
- アイコン: https://heroicons.com/

## GraphQL code generate

```
pnpm codegen
```
